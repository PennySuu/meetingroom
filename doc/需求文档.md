# meetingroom

## 需求背景

公司有多间会议室，目前靠即时通讯群里喊一声来"占位"，经常出现：

- 到了会议室发现被别人占了，双方都认为自己预约了
- 同一个人同时占了好几间会议室，其他人无房可用
- 不清楚哪些时段空闲，需要逐个问或去现场看

需要一个在线会议室预约平台，支持查看空闲时段、在线预约。

## 产品方案

### 页面规划

**会议室列表页**：展示所有会议室，每间显示名称、位置、容纳人数、设施标签（投影、白板、视频会议等）。支持按容量和设施筛选。

**预约日历页**：选择会议室后展示时间表视图，已预约时段高亮，空闲时段可点击发起预约。展示我的预约列表。

### 核心业务流程

```
浏览会议室列表 → 查看某间会议室的空闲时段
  → 选择时段发起预约（填写会议主题）
  → 系统检测冲突（同一会议室时段冲突 + 同一用户时段冲突）
  → 预约成功
```

### 业务规则

- 会议室数据初始化预置，无需在线创建
- 预约以时间段为单位，需指定开始和结束时间
- 同一会议室同一时段只能有一个有效预约（不允许时段重叠）
- 同一用户同一时段只能预约一间会议室（防止一人占多室）
- 单次预约时长有上限（如不超过 4 小时）
- 不能预约过去的时间

## 功能清单

### 会议室查看

- 会议室列表：展示名称、位置、容量、设施
- 支持按容量、设施筛选
- 查看指定会议室指定日期的空闲时段

### 预约管理

- 创建预约（会议主题、时间段），需同时校验：
  - 该会议室该时段无其他有效预约
  - 该用户该时段未预约其他会议室
- 我的预约列表（支持按会议室、日期范围筛选，支持分页）
